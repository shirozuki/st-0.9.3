# shirozuki's [st](https://git.suckless.org/st/) build

## Modded with the following patches:
1. [Xresources](https://st.suckless.org/patches/xresources/)
2. [Alpha](https://st.suckless.org/patches/alpha/) - alpha configurable via Xresources

## Usage
Best used with [tmux](https://github.com/tmux/tmux) - it handles scrollback and the like, so there's no scrollback patch here. If you need a sample tmux config to start from, grab one from my [dotfiles](https://github.com/shirozuki/dotfiles).

## Installation
To install st simply run:
```
# make install clean
```
